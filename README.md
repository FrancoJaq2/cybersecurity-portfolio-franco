🛡 Identificación de Vulnerabilidades con Nmap
Este repositorio documenta un laboratorio práctico de ciberseguridad, orientado a cumplir requisitos reales solicitados en ofertas laborales para roles como Analista SOC y Analista de Ciberseguridad.
🎯 Objetivo del proyecto

Identificar servicios expuestos en un host dentro de un entorno de laboratorio controlado, utilizando técnicas básicas de reconocimiento de red.
🧪 Entorno de laboratorio

    Máquina atacante: Kali Linux

    Máquina objetivo: Ubuntu

    Virtualización: VMware

    Red interna aislada

Este laboratorio se ejecutó exclusivamente con fines educativos.
🛠 Herramientas utilizadas

    Nmap

    Kali Linux

    Ubuntu Server

🔍 Actividad realizada
Análisis técnico del escaneo Nmap
Resumen del hallazgo

Escaneo de puertos y detección de servicios

Identificación de servicios expuestos

Documentación de resultados

El ejercicio cumple un objetivo formativo enfocado en reconocimiento y análisis inicial, alineado con tareas básicas de un Analista SOC.

Comando utilizado: sudo nmap -sV -Pn <IP_OBJETIVO>
